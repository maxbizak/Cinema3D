# 3D Кинотеатр 1.0.2

## Установка на ноутбуке

1. Распакуйте весь архив в отдельную папку.
2. Запустите `INSTALL-ON-LAPTOP.cmd`. Скрипт скопирует приложение в `%USERPROFILE%\3D-Cinema`, загрузит FFmpeg и yt-dlp и создаст ярлык. Для первого запуска нужен интернет.
3. Подключите проектор, включите «Расширить экраны», выставьте для проектора 120 Гц и выберите его в приложении. Нажмите «Тест очков».

## Видео из браузера

Нажмите «Браузер → проектор», выберите экран ноутбука и формат ролика. Если две картинки находятся рядом, выберите **SBS**. Разверните ролик на весь экран в браузере. Звук, пауза и перемотка остаются в браузере; пульт программы управляет только изображением на проекторе.

## Фильм файлом

Нажмите «Открыть файл…» или положите MP4/MKV в `movies`. Формат SBS/OU и встроенную звуковую дорожку можно выбрать в главном окне. Если звук отдельным файлом, нажмите «Выбрать MP3/WAV…». Программа скопирует дорожку в `movies\audio`, чтобы она переносилась вместе с папкой.

## Изменение кода в Cursor

Откройте в Cursor папку `%USERPROFILE%\3D-Cinema`. Исходники приложения находятся в `native\Cinema3D`. После изменений закройте приложение и запустите `BUILD-APP.cmd`: предыдущий EXE сохранится как `Cinema3D.exe.bak`. Затем снова откройте ярлык.

Чтобы Cursor мог получать следующие версии командой `git pull`, сначала клонируйте публичный репозиторий `https://github.com/maxbizak/Cinema3D.git` в пустую папку `%USERPROFILE%\3D-Cinema`, а затем запустите установщик из архива выпуска. Установщик добавит EXE и инструменты в эту папку, сохранив `.git`. Если папка уже занята старой установкой, сначала сохраните свои фильмы и настройки в другом месте.

Работу DLP 3D на проекторе и очках необходимо проверить на самом ноутбуке. Защищённые от захвата ролики могут отображаться чёрными.
